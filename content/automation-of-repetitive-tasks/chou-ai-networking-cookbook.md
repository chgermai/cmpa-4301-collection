**Source:** Chou, E. (2026). *AI Networking Cookbook: Practical recipes for AI-assisted network automation and development.* Packt Publishing.

**What it covers:** A cookbook-style book of practical recipes for using AI and large language models in network automation. The book covers OpenAI integration, prompt engineering, running local LLMs with Ollama, LangChain, and building a network "co-pilot" for monitoring, security, and configuration tasks.

**Why it's valuable:** Eric Chou has over 20 years of network engineering experience at companies like Amazon and Microsoft, and he also hosts the Network Automation Nerds podcast. The recipe format means each section is an independent example instead of a bunch of theory, making it easy to pull out one technique at a time.

**Who would find it useful:** Engineers who already script network automation in Python and want to add AI capabilities onto that existing skill set, rather than start from scratch.

**Limitations:** It assumes comfort with Python and basic networking concepts. It's also a fast-moving space, and some of the specific tool integrations (model APIs, libraries) are likely to age quickly as technology evolves.
